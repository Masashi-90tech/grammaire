- **文法・例文の校正**：解説・ドリル・単語カードの誤りや不自然な箇所を25か所修正（修正前後の記録つき）。

- **書き下ろし長編小説『Ce que la nuit a entendu（夜が聞いていたこと）』**：C1–C2 の文芸小説、全12章・約10,700語。夜行列車から消えた老人の謎を、一晩分の録音の「音」だけで解いていく物語。地の文を**単純過去**と**複合過去**で切り替えて読める（台詞は変わらない）。変わる語の色分けと、もう一方の版の併記つき。「学習 → 物語を読む」の先頭にある。

公開後、開いていたアプリには画面下に更新の案内が出る。「更新する」を押すと新しい版に切り替わる（学習記録はそのまま）。

## 今回のUI更新

- 配色は4種類。従来のラベンダーとクラシックを残し、やわらかい青・落ち着いた緑を追加。ライト／ダーク／端末追従に対応。
- 配色と単語一覧形式を別々に設定。フランス語本文は16・18・20px、余白はゆったり／コンパクト。
- 下部にホーム・学習・辞書・その他。ホームを短くし、学習内容を目的ごとに整理。進行中のドリルでは従来の中断確認を使うため、下部ナビを一時的に隠す。
- 文法は検索＋分類ごとの折りたたみ。従来の80トピックとドリルを維持。
- 辞書一覧は20件ずつ。詳細は意味・例文／活用／使い方の3タブ。活用は選んだ1時制を表示。検索語・ページ・スクロール位置・選択時制を維持。
- スワイプは左側から右へで戻る、右側から左へでメニュー。画面の外端を避けて指1本分ほど内側から始める。入力欄やボタン上では作動しない。設定で無効化でき、通常のボタンも残す。
- 「学習 → 声に出して読む」に独自教材6本。日本語訳と区切り表示、標準／ゆっくり、一文再生、4秒間隔の3回リピート、全文再生、言い換えのお題、練習済み記録。
- 音読の再生は停止・画面移動・アプリが背面に回ったときに解除。音読の練習記録も進捗書き出し／読み込みに含む。

音読は端末の音声を使用。Gemini等で生成した音声の埋め込みはまだなく、自然さやオフライン音声の有無は端末の設定による。教材の文章自体はアプリと一緒に保存される。

配色は「その他 → 配色・レイアウト」で変更。更新時は既存の配色と学習履歴を保持する。

## オフラインと容量

初回はインターネット接続が必要。通常の学習用文字データは起動時に読み込み、辞書の詳細だけを必要時に追加する。すべての教材を画面単位で遅延読み込みする実装ではない。

「動詞辞書 → 収録状況・オフライン利用 → 辞書全体をこの端末に保存」で未閲覧の見出しも保存できる。保存の完了を確認してからオフラインにする。ブラウザーによる保存データの消去やアプリ更新後には再保存が必要になる場合がある。

学習履歴は端末内に保存。同じ公開URLで更新すれば引き継がれる。別の公開URL・別ブラウザーへ移す場合は既存の進捗書き出し／読み込み機能を使う。

## 再ビルド

Python 3.9以上で、このフォルダを作業ディレクトリとして `python3 build.py` を実行する。外部パッケージは不要。`site/` と、全データを埋め込んだ互換用 `grammaire.html` を出力する。通常の配信には `site/` を使う。

Node.jsがあれば `node test_ui.mjs` と `node test_dictionary.mjs` でデータ・検索・出題ポリシー・活用の代表例・キャッシュ処理の回帰確認を実行できる。これは全訳文の品質やブラウザー全機種の動作を保証するものではない。

## 続きの編集

`verb_dictionary/authored-*.jsonl` が作成済みの訳と独自例文。元の既存語彙は `gen/`、活用原表は `verb_conjugations_source.csv`。

`editorial/resume.json` に各担当の保存状況と未作成語、`editorial/authoring-part-*.json` に参照語義・URLがある。日常語・専門語を優先し、地方語・古語は別トピックへ後回しにする。ただし検索からは消さず、練習問題に混ぜない。

`DICTIONARY_REVIEW.md` が修正概要、`verb_dictionary/conjugation-corrections.json` が修正前後の全記録。`editorial/conjugation-reference-audit.json` は誤りと確定していない差分候補。続きの担当は、差分候補をそのまま正解として採用しないこと。

意味の参照資料は検証用。参照されたすべての訳を採用する意図ではない。必要な意味を選び、日本語・英語の説明と自然な例文を独自に作成する。疑わしい語を穴埋めで捏造しない。

## 配信用ZIPの入れ方

`grammaire-ui-github-pages.zip` を解凍し、その**中身を全部**、今の `index.html` がある場所へアップロードする。`assets`、`data` などのフォルダ構造を維持する。ZIP自体や、その外側のフォルダを置くだけでは動かない。`.md` は説明書なので一緒に置いて構わない。

`grammaire-ui-project-source.zip` は次回の編集・Claudeへの引き継ぎ用。GitHub Pagesに置く必要はない。`grammaire-ui-preview.html` は全データ入りの単体確認用。

更新前に「その他 → 進捗を書き出す」で履歴を手元に保存できる。配信先のドメイン・ブラウザーを変えずに更新すれば、既存の保存キーをそのまま使う。キャッシュだけで古い版を表示している場合は、オンラインで一度開き、アプリとタブをすべて閉じてから開き直す。辞書全体のオフライン保存も更新後に再確認する。
