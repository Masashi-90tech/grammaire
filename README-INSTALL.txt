【今回の変更】
既存の動詞5,346件に、同梱単語カードの動詞以外6,772件を追加。合計12,118件です。同じ綴りでも品詞が異なる項目は別に数えています。カードの動詞1,407件は追加対象から除き、既存の動詞辞書を使います。

辞書の検索欄の下にある「品詞」を開いて、チェックボックスで複数選択できます。初期状態はすべて選択済み。「すべて選択」と「選択解除」もあります。熟語・表現は品詞とは別の欄です。

一覧とカードの両方で品詞を表示。「詳しく見る」から日本語・英語・例文、語法、名詞の性など既存カードの情報を確認できます。ほかの意味と追加例文は折りたたみ式です。動詞にはこれまでどおり活用を表示します。

品詞の選択・検索語・閲覧位置はこのブラウザーに保存します。ランダム表示も現在の検索条件に従います。アプリ全体の検索からも辞書の詳細へ進めます。

学習カード、練習問題、学習記録、校訂済みの物語は従来のままです。外部Ankiデッキを新しく取り込む機能の追加や、音声データの生成は今回の対象に含めていません。

【更新とオフライン】
更新後はオンラインで一度開き、アプリのタブを閉じて開き直してください。動詞以外の語彙はアプリのデータと一緒に保存されます。動詞の全詳細もオフラインで使うなら、辞書内の「収録状況・オフライン利用」から「辞書全体をこの端末に保存」を実行してください。

【確認】
検索・品詞の複数選択・表示・保存の復元、活用とオフラインキャッシュのテストを実施。追加した6,772件の全項目を元のカードと照合。既存の11データセットと34個の動詞データファイルの一致も確認しました。実機での見た目とタッチ操作は未確認です。
