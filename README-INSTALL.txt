# 更新内容と導入方法 — 2026-10-04

Downloadsのgrammaire.htmlのホーム画面を土台に、最新版の教材と操作改善を統合しました。

## ファイルの使い分け

- grammaire-github-pages.zip：現在のGitHub Pagesを更新する配信用。
- grammaire-project-source.zip：Claudeなどへ渡す編集用。生成用のコード・教材・検証を収録。
- grammaire.html：全教材入りの単一HTML。
- 追加教材.json：今回の基本語12語・組み合わせ24項目・場面会話8本のデータだけ。
- source/grammaire_ui/reference_review/：先に検討した追加132語と未採用候補の資料。

## GitHub Pagesの更新

1. 配信用ZIPを解凍する。
2. ZIP内のindex.html、assets/、data/、アイコン、manifest.json、service-worker.jsを、現在のindex.htmlがある場所へまとめてアップロードする。フォルダ階層を保つ。
3. 公開更新後に、通信のある状態で現在のアプリを一度開く。アプリを閉じて開き直すと新しい版に切り替わる。ほかのタブでも同じアプリを開いている場合はそちらも閉じる。

見た目は旧ホームをベースにしていますが、内部の読み込み処理も変更したため「データだけ」をアップロードする方法では更新できません。配信用一式を差し替えてください。同じURLを使えば学習履歴を引き継げ、ホーム画面のアイコンを追加し直す必要はありません。

README-INSTALL.txtは案内文なので、動作に必須ではありません。教材やソースのmdをGitHubへ追加する必要はありません。

## オフラインに備える

オンラインで更新版を一度開き、閉じて開き直してから、次を実行してください。

- 「その他」→「教材をまとめて保存」。
- 「辞書」→「オフラインの保存」→「辞書全体をこの端末に保存」。

完了表示と保存状況を確認すれば、保存済みの教材をオフラインで使えます。まだ保存していない詳細や新しい教材は、オンラインで取得する必要があります。

## 今回の改善

- 旧ホームに辞書・文法の入口を追加。
- 画面の左側から右へスワイプして前画面へ戻る。辞書カードの中央は前後の単語を切り替える。
- ホーム表示を全教材の読み込み待ちにせず、辞書と文法の必要データを分割。
- 辞書を開く時の必要データ量は約4.1MBから約2.1MBへ削減（圧縮前）。
- 基本語の用法36例、24の組み合わせ、8場面会話・8作文課題を追加。
- 既存の辞書・学習記録・物語の本文と日本語訳を維持。

スマホ幅の表示と主要操作、自動チェックを確認済み。実機のスワイプ感と起動秒数はまだ測定していません。
