# 宿題メーカー（JLPT N5・N4）

日本語の宿題を作るための、先生用のツールです。N5・N4 の語彙リストから単語を選ぶと、問題を自動で組み、スライド（16:9）か A4 の PDF にできます。フランス語アプリ（grammaire）と同じく、1つの HTML ファイルで動き、オフラインで使えます。API キーは使いません。

## 使い方

1. `dist/shukudai.html` をパソコンのブラウザー（Chrome・Edge・Safari）で開く。
2. **① 単語**: N5／N4 のリストから語をタップして選ぶ。番号の範囲でまとめて選んだり、使っていない語からランダムに選んだりもできる。✎ で英語・フランス語の意味を入れたり、表記を直したりできる。「意味をAIで付ける…」は、AI に貼る依頼文を作る（このツールからは送信しない）。
3. **② 問題**: 問題の種類と数を決める。
   - 単語から自動で作る問題: 単語リスト／読み方を書く／漢字で書く／意味を書く／日本語で書く／線で結ぶ／動詞の形を変える／文を作る
   - 自分で書く問題: 穴埋め・並べ替え・質問。`{図書館|としょかん}` でふりがな、`[答え]` で穴埋め、` / ` で並べ替えの区切り、` => ` で答えの例を書く。AI に作ってもらう依頼文も作れる。
   - 漢字の範囲（N5 の字／N4 までの字／自分で指定）を決めると、範囲外の漢字にふりがなを付けたり、問題から外したりする。
4. **③ 印刷**: 言語（日本語のみ／日本語＋英語／日本語＋フランス語／英語／フランス語）、ふりがな、形、こたえの付け方を選んで「印刷・PDFにする」。学習者によって言語を変えたいときは、切り替えてもう一度 PDF にする。
5. **一覧**: 作った宿題の一覧。複製して次の回を作れる。前の宿題で使った語は ① で「使用」の印が付く。データはブラウザーの中だけに保存されるので、「書き出す」で控えを取っておく。

iPhone・iPad の「ファイル」から HTML を開くと、プレビュー表示になってボタンが動かないことがあります。その場合はパソコンで使ってください。

## ファイル

| ファイル | 中身 |
|---|---|
| `src/lib.js` | 画面に依存しない処理: ふりがなの割り当て、動詞の活用、漢字の範囲、問題の記法、AI 用の依頼文 |
| `src/app.js` | 画面: 単語選び・問題の編集・ページ割り付け・印刷・保存 |
| `src/style.css`, `src/template.html` | 見た目と HTML の枠 |
| `extract_vocab.py` | Langoal の「JLPT N5／N4 語彙一覧」PDF から語・読み・品詞を取り出して `data/vocab.json` を作る |
| `build.py` | 上をまとめて `dist/shukudai.html` を作る |
| `test/test_lib.mjs` | ふりがな・活用・記法などの確認（全動詞の活用も確認する） |
| `test/test_e2e.mjs` | ブラウザーで操作して、プレビュー・PDF のページ数・保存を確認する |

## 作り直すとき

```sh
pip install pdfplumber
python3 extract_vocab.py --n5 "JLPT_N5….pdf" --n4 "JLPT_N4….pdf"   # data/vocab.json
python3 build.py                                                  # dist/shukudai.html
node test/test_lib.mjs
node test/test_e2e.mjs        # Playwright が必要
```

## データについて

- `data/vocab.json` と `dist/shukudai.html` は Langoal の一覧（第三者の資料）から作るので、公開リポジトリには入れていない（`.gitignore`）。作り直すときは手元の PDF から `extract_vocab.py` で作る。
- PDF の印刷が崩れていた N4 の9番は入れていない。品詞の明らかな誤り（組み立てます・引っ越しします）と欠け（掃除機）は `extract_vocab.py` の `FIXES` で直している。
- 漢字の範囲（N5 79字・N4 167字）は、一般に出回っている JLPT 漢字リストを参考にした目安。JLPT の公式な出題基準ではない。
- 動詞の活用は、品詞（五段・一段・不規則）とます形から規則で作る。行く・ある・いらっしゃる などの例外は `lib.js` で扱っている。わかる・できる などは、可能形・命令形などを作らない。
